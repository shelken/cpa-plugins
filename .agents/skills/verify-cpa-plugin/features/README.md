# 插件特性验证地图

本目录定义 CPA 插件用户视角的功能特性与自动化驱动方法

## 特性列表

- [插件装载与配置](plugins-config.md)：管理面板插件加载与可视化配置字段
- [登录与凭据保存](auth.md)：扫码登录流程与本地账号归属
- [模型清单报送](models.md)：客户端模型列表与黑名单过滤
- [额度状态查询](quota.md)：实时套餐余量与版本门禁

## 驱动约定

- 所有管理面命令均通过 `scripts/management-api.go` 执行，自动通过 `sec-run` 注入 `CPA_TOKEN`
- 生产环境默认执行只读操作，写操作（如更新配置）须显式确认
- 离线验证优先使用本地沙箱 `scripts/dev-sandbox.go` 驱动，不依赖生产网络
